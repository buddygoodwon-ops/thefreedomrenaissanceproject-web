# thefreedomrenaissanceproject.com

Static site (Cloudflare Pages) styled after slamdunktechnologies.com, with the open-sky frontier mood of eurekaitsbitcoin.com.

- Pages are generated by `python3 build.py` (needs pandoc for `white-paper.html`, built from `paper.md`).
- Registration posts to `functions/api/register.js` (Cloudflare Pages Function).
  - Bind a KV namespace as `REGISTRATIONS` in the Pages project settings.
  - Optional env var `NOTIFY_WEBHOOK` (e.g. a Zapier catch hook) forwards each signup.

Deploy: connect this repo to a Cloudflare Pages project (no build command, output directory `/`), then add the custom domain www.thefreedomrenaissanceproject.com.
